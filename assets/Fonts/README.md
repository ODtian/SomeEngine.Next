# Example font

`Example.otf` is the renamed Noto Sans CJK SC subset used by the Typography
public behavior fixtures. It retains ASCII, accented Latin characters and
`中文你好世界爱`, including the text displayed by the screen panel example.
`OFL-Example.txt` contains its SIL Open Font License.

The original font and subset provenance are recorded in
[`Typography test fonts`](../../tests/SomeEngine.Typography.Tests/Fonts/README.md).
The Runtime assembly embeds this font and ships its license beside the output.
