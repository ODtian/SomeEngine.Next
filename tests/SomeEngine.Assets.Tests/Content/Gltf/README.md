# MikkTSpace reference data

`mikk-reference.json` contains vertex inputs and one tangent `(x, y, z, sign)` per triangle corner. The reference function is `genTangSpaceDefault` from [mmikk/MikkTSpace](https://github.com/mmikk/MikkTSpace/tree/3e895b49d05ea07e4c2133156cfa94369e19e409), commit `3e895b49d05ea07e4c2133156cfa94369e19e409`.

The reference data is generated by an independent C executable using the upstream files and callbacks for these inputs. It uses three corners per face and the default 180 degree threshold. Float outputs are written with nine significant decimal digits, enough to preserve float32 values. The importer tests compare every component with an absolute tolerance of `1e-6`.

- `mirrored-uv`: shared source vertices receive opposite tangent signs across the mirrored texture region.
- `smooth-skew`: adjacent triangles have different UV derivatives; reference output includes MikkTSpace's grouping and angle weights.
- `degenerate-uv`: one triangle has collapsed UVs; the reference supplies its degenerate handling.

The tests place these UVs in `TEXCOORD_1`, put different values in `TEXCOORD_0`, and select the former with `normalTexture.texCoord`. They also verify source normal, UV and morph values after corner expansion. Test files are created through the public glTF loading API and removed when each test finishes.
