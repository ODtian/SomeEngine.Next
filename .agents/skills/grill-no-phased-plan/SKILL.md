# Grill: No Phased Plans

Plans must be **one-step-to-final**, not phased.

Forbidden language:
- "第一阶段" / "phase 1"
- "先不做" / "skip for now"
- "一期" / "前期只做" / "initial version only"

If a plan genuinely requires sequencing, the grill must produce the **final end-state plan** with the sequencing as dependencies, not as "do this later".

Partial deliveries are a smell: either the scope is unclear (re-grill) or the agent is avoiding a hard refactor.
