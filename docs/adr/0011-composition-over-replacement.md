# 库与用户代码对等，定制通过组合完成

SomeUI 提供的元素、控件、布局和行为只是用公开部件组合出来的普通代码。用户需要不同的东西时，用同样的部件组合出自己的版本；系统中不存在修改别人组件的机制。

因此不设计替换（`Replace`/`Map`）、覆盖层（`Override`）或具名内容槽。复合控件拆成由调用方拼装的公开部件；视图只按类型声明子节点来源（`Build` 或 `Caller`），不定义内部结构契约。组件需要决定内容放置时机时接收内容函数参数。

对等由程序集边界保证：内置元素程序集只使用底层公开 API，不使用 `InternalsVisibleTo`。每个内置控件有一个在外部程序集中只用公开 API 重写的等价版本，用行为测试证明二者一致。

用户在 2026-10-03 确定。
