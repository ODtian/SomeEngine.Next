# 依赖按版本拉取校验

SomeUI 的计算在读取时登记 `(来源, 版本)`，每帧在视图重建阶段统一比较版本，变化的计算才重新执行。写入只推进版本，不推送通知，也不需要回到某个线程派发。

依赖来源是 ECS 组件、实体结构、查询成员、祖先环境数据，以及任意持有 `VersionCell` 的对象。外部数据不必进入 ECS；游戏系统要模拟、存档或渲染读取的数据仍放在 ECS。`State<T>` 用 seqlock 保证任意线程读写得到完整值，读改写使用 `Update`。

选择拉取是因为 ECS 已有写版本、ref 写入没有回调可推送，且拉取天然支持跨线程写入。代价是每帧的版本扫描，用按组件类型的全局写版本整批跳过未变化的类型。

用户在 2026-10-03 确定。
