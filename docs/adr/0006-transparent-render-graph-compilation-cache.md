# Cache Render Graph compilation transparently and publish plans at safe boundaries

Every render invocation still records its actual graph, but freeze computes an exact canonical signature and transparently reuses an immutable internal Compiled Graph Plan when available. On a cold miss, exact validation and deterministic conservative lowering produce the correct plan for the current invocation. A single-flight worker compilation is started only when an enabled compiler policy can produce a meaningfully different optimized plan; with alias placement and raster merging both disabled, the conservative plan is the only useful plan and no duplicate background compile is launched. If conservative lowering cannot satisfy a hard capability or memory constraint, the invocation instead starts or joins the required exact optimized result and waits before plan binding. The worker submits an immutable candidate to the Render Coordinator, which alone drains, orders, and revalidates candidates at plan-selection boundaries after Freeze and before plan binding: normally immediately before exact cache lookup, or after the required same-key join when no legal conservative plan exists. It never mutates a live plan, resumes through the arbitrary caller's synchronization context, exposes templates/cache keys/compiled handles, or substitutes a stale different-signature plan. A background candidate arriving after the normal boundary waits for the next invocation, an invocation pins the selected plan for its CPU use, and cache eviction removes lookup visibility before deferred managed retirement rather than forcing device-wide idle.

## Implemented lifecycle

`CompiledGraph` is the cached value: an invocation-independent payload containing live sets,
execution batches/record units, dependencies, barrier templates, relative placements, raster
groups, and diagnostics. `CompilationCache` is the cache mechanism and policy owner. It never
caches physical resources, native views/descriptors, command contexts/lists, callbacks, imported
handles, fence values, or clear values.

The cache is owned by one `RenderGraph` and permanently scoped to its device domain. An exact key contains both the canonical hash and canonical bytes plus device/compiler semantic generations and compiler-policy bits; hash equality alone never produces a hit. Readiness fence values remain invocation data, while their normalized queue shape stays in canonical/detached compiler data because it can constrain submission grouping. Default retention is 128 entries and 64 MiB of deterministic estimated managed payload. Setting either limit to zero disables reusable lookup while preserving the producing invocation's lease; an individually oversized plan is also never admitted. Coordinator access ordinals drive a deterministic LRU. An active invocation lease is the sole correctness pin for this pure managed payload, allowing a temporary aggregate budget overage without a device-wide wait. Replacement and eviction first remove lookup visibility, then retire the old managed plan after its CPU lease clears. Physical resources, views, descriptors, command objects, and other native invocation state have a separate RHI lifetime and retire against their exact submitted queue completions; those GPU completions do not pin `CompiledGraph`.

Worker completion is a candidate enqueue, not publication. Each coordinator drain fixes its candidate count before dequeueing; a callback arriving after that snapshot remains queued for the next boundary. Failed optimized compilation leaves the conservative resident usable and marks that exact resident so later hits do not create a per-frame retry storm. Its diagnostic retains canonical signature, frozen pass names, failure stage, and exception. Disposal requires all invocation leases to be released and completes outstanding compiler jobs, but it neither publishes terminal candidates nor counts shutdown cleanup as runtime eviction/publication. It releases the pure managed plan payload without extending ownership to invocation handles, callbacks, descriptors, transient resources, or native command objects.
