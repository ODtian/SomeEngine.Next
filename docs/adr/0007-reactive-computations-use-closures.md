# 使用 C# 闭包表达响应式计算

前端使用 C# 闭包保存需要随数据变化重新执行的计算。用户通过闭包明确计算范围，并在其中沿用普通 C# 的赋值、局部变量、控制流和方法调用；框架利用 C# 的捕获与调用语义保存和重新执行这些计算。

闭包描述计算的保存方式，重新运行描述计算的执行行为。同一前端可以同时使用声明方法重跑和局部闭包重跑，具体计算的调度由依赖关系决定。

> 2026-10-03 起由 [ADR 0009](0009-struct-views-and-frontend-reconciliation.md) 替代：重跑单元默认是 struct 视图，闭包只用于 Solid 前端的计算与组件主动调用的内容函数。
