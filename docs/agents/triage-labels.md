# Triage 标签

技能使用下表中的角色名称；GitHub Issues 使用对应的同名标签。

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估的任务 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求与验收标准已明确，供代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 已决定搁置的请求 |

每张经过 triage 的任务票维护一个状态标签，并按内容使用 `bug` 或 `enhancement` 类别标签。

状态变化时，替换原状态标签，并把已确认的信息与后续所需信息记录在 Issue 讨论中。
