# DefaultGame 启动与 NativeAOT 验收

对应 #203。源码基点为 be6be444f639d9e786914d4b3661f8b8e9441bd0，当次工作区改动完成以下迁移。

## 定位与实现

原 DefaultGame Release 产物运行托管 IL。14 秒 EventPipe 定位采样中，启动线程编译 5682 个方法，JIT 区间累计约 6000 ms。原启动设备创建约 2287 ms、图协调约 2675 ms，材质 shader 入口准备在图协调阶段等待 Slang 后端。

Release 构建现在直接产出 NativeAOT 可执行文件，启动入口核对这一运行方式。场景配置、性能报告和 trace 元数据使用生成的 JSON 代码。场景世界及材质加载与设备创建重叠；Shader 持有并复用异步取得的 Slang 入口数据。设备使用后端的默认适配器选择。

计时终点为粗几何就绪后成功呈现的场景帧。F9/F10 在首次场景呈现后开始三场景反馈，冷启动与场景重载分别记录。呈现 pass 的缺页反馈依赖在持久图中建立，当帧纹理上传完成依赖通过原图表达，首帧图像读回经过同一应用路径。

## NativeAOT 进一步优化

本轮以以上 2982.56 ms NativeAOT 结果为基线，保持同一机器、内容、1280×720、256 MiB、TAA、VSM、异步计算与场景行为。常规采样继续使用 `tools/Measure-Scenes.ps1`。最终窗口到首个场景帧为 **1697.94 ms**，缩短 **1284.63 ms（43.07%）**；应用入口到首帧为 2275.72 ms，窗口显示前为 577.78 ms，首帧索引为 1。

启动 trace 定位到 Slang 入口资源分析与设备创建。原调用路径对所有材质入口排队，首帧调用 18 次 `GetEntryPointMetadata`；Slang 在该 API 中生成入口后端结果。材质加载与实际材质阶段现在共用入口选择，公共入口随材质加载开始，设备相关入口在设备创建后开始，最终启动 trace 共有 6 次分析请求。每个结果由驻留 Shader 共用。保存代码加载的 Slang 会话使用最少优化与基础优化级别完成补充分析，GPU 使用原编译设置对应的保存代码。D3D12 适配器选择同时创建供引擎使用的原生设备，最终 trace 的原生创建设备调用为 1 次。

| 常规启动阶段 | 基线 | 优化后 |
| --- | ---: | ---: |
| 设备创建 | 1122.21 ms | 947.92 ms |
| 渲染资源建立 | 167.66 ms | 160.81 ms |
| 首次图协调 | 1584.91 ms | 469.34 ms |
| 首次帧执行 | 79.30 ms | 102.82 ms |

最终三场景反馈含应用启动共 **28.71 秒**，`Complete=true`、`NativeAot=true`、`TraceEnabled=false`，三个场景均为 `Measured`。

| 场景 | 样本 | P50 | P95 | 场景首帧 |
| --- | ---: | ---: | ---: | ---: |
| 1024 小球 | 502 | 3.94 ms | 4.43 ms | 315.77 ms |
| Sponza | 622 | 3.13 ms | 4.27 ms | 2032.94 ms |

单独 trace 反馈共 29.07 秒，窗口到首帧 1784.36 ms。启动 trace 中单次原生设备创建为 662.80 ms，最长入口分析为 1292.69 ms；入口分析与设备创建重叠，图协调仍等待设备相关入口完成。启动及三场景 trace 均完整，丢失事件及作用域错误均为 0。常规报告与 trace 报告分别保存在验收数据的 `NativeAotOptimization` 字段。

检查结果：应用首帧、取消及图像交付 3 项通过；Slang 入口资源行为 23 项通过；D3D12 WARP 能力行为 16 项通过。各测试入口执行行为规则自动检查。
