## 实现结论

所有 A 项沿创建、修改、取消、提交和结束的责任边界核查后集中处理实现缺陷。最终只通过 Game World→Render World 转移场景语义；资产版本可共享但不在渲染帧中跟随源对象修改。图持有依赖、范围状态和提交事实，实例及上传存储分别持有自己的可写代次与字节。

新增集成验证还修复了单项旧测试无法覆盖的问题：从空场景安装材质时的外部上传扩容、常量缓冲更新后的对齐、公共着色阶段被重复添加、HiZ 首阶段及缺页/统计回读缺少对新增光栅和遍历工作的顺序约束、一次启用多个 pass 后的局部排序传播、Whole 边界范围被直接切分，以及将整帧完成集合误当成回读缓冲自身队列归属。

Vulkan 现在保留公开 Slang 布局的资源顺序，不再按 SPIR-V 活跃资源另建调用方参数表，也不按绑定类型猜测重排。灯光功能在创建期复用已有布局解析，帧循环不做反射。

## B/S 逐项结果

表中的“处理”说明代码路径；不是声称所有硬件组合、失败注入点都已逐一执行。实际执行范围见后文。

| 项目 | 原问题 | 处理 |
| --- | --- | --- |
| B01 | Execute 参数错误后丢失帧清理入口 | 执行参数校验位于消费帧之前；错误后仍可重试或释放。 |
| B02 | 已提交编辑的副本仍能修改发布结构 | 所有编辑副本均校验同一活动 token，提交后的副本失效。 |
| B03 | 旧 pass 定义能写进复用后的新帧 | 帧 pass 定义携带帧身份，不能修改复用后的帧。 |
| B04 | 放弃编辑会复用已经发出的资源身份 | 放弃编辑不回退已发出的身份代次。 |
| B05 | 同步解析失败污染后续帧的缓存 | 同步候选全部推导成功后才替换旧缓存；失败保留待消费变化。 |
| B06 | 动态 pass 声明失败留下范围读取 | 动态声明失败同时撤销范围读取登记。 |
| B07 | 添加已有 pass 的 rendering region 未标记结构变化 | 新增 rendering region 触发对应 pass 的结构变化；region 身份包含所属 pass。 |
| B08 | 分配回滚留下已释放资源引用 | 回收与回滚以实际保留项为准，失败不清空尚须释放的资源。 |
| B09 | 帧绑定的外部 buffer 完成查询漏报 | 范围完成查询包含帧绑定的外部缓冲以及已接受的部分提交。 |
| B10 | 提交数组被拒绝后命令停留在 Submitting | 命令与交换链声明逐个记录已取得前缀；失败只撤销真实取得的部分。 |
| B11 | 写入 scope 的旧副本能释放新 scope 的锁 | 写入能力带代次，旧副本不能结束后续写入。 |
| B12 | 实例第二代改写不满足 Vulkan 映射规则 | prepare 持有一次映射；非一致内存的刷新覆盖实际写入范围。 |
| B13 | 相同排序字段得到不同布局哈希 | 先排序最终字段，再计算布局身份；公共布局测试覆盖相反输入顺序。 |
| B14 | 正交投影的非零抖动完全无效 | 按投影的 W 列施加平移，透视与正交投影均产生指定 NDC 偏移。 |
| B15 | 派生材质属性覆盖继承属性的存储位置 | 派生属性以基类总属性数为偏移，不再复用基类存储位置。 |
| B16 | 变化日志截断后把不完整变化标成已覆盖 | 变化历史缺口保留全范围刷新语义，不把截断后的片段声称为完整覆盖。 |
| B17 | 实例化实体的材质变化读取不存在的 MeshInstance | 实例集合、普通网格共享材质变更提取与镜像发布通路。 |
| B18 | 物体停止移动后 previous transform 不前进 | 共享 transform 统一保留；停止移动后 previous transform 在下一提取边界前进。 |
| B19 | 窗口 resize 后视图尺寸与渲染资源尺寸分离 | 固定渲染分辨率与窗口呈现分辨率分别使用；resize 不隐式重建功能。 |
| B20 | 索引 BLAS 用顶点数计算三角形数 | TLAS 实例数与各 BLAS 几何的 primitive 数分别传给原生构建。 |
| B21 | 逻辑混合操作直接转换到不同顺序的原生枚举 | 逻辑混合操作逐项映射 Vulkan 枚举。 |
| B22 | 渲染区域内的查询先执行禁止在区域内调用的 reset | 公开 ResetQueries；图在 rendering 之前重置完整写入范围，BeginQuery 不再隐式 reset。 |
| B23 | shader table 的记录数被误限于 shader group 数 | shader table 按记录数与 shader group 身份分别构造。 |
| B24 | 普通非方形数组纹理被错误标成 cube compatible | 只有符合 cube 形状及层数要求的纹理启用 cube compatible。 |
| B25 | predication buffer 缺少原生 conditional rendering usage | predication 缓冲包含 conditional rendering usage。 |
| B26 | 普通 shading 同步掩码无条件包含光追 stage | 普通 shading 同步范围只包含设备实际启用的 shader stages。 |
| B27 | D3D12 整子资源复制仍传入 source box | buffer 与 texture 的复制参数按原生资源种类构造。 |
| B28 | 可选队列专用 COMMON 模式破坏跨队列类型交接 | 队列专用 COMMON 访问与布局转换使用队列类型对应的映射。 |
| B29 | D3D12 单 cube view 忽略起始数组层 | cube view 的 FirstArrayFace 以面为单位。 |
| B30 | bindless 空值被跳过写入而非形成空 descriptor | 数值槽回收与描述符内容更新独立；重新分配后可再次写入。 |
| B31 | candidate 容量末尾的线程先越界读再检查 | 候选读取前先限制到真实缓冲容量，处理不整除线程组的尾部。 |
| B32 | 允许的遍历容量可产生超出上限的一维 dispatch | 遍历间接分派使用二维组数，shader 展平组索引。 |
| B33 | 离轴球体光源的屏幕范围不是保守包围 | 投影包围球的八个包围盒角点，处理近平面和正交、偏心投影。 |
| B34 | 非均匀 stretch 后法线仍只做旋转 | 法线使用逆缩放，切线重新正交化并保留镜像手性。 |
| B35 | 一次加载失败永久占住资产缓存项 | 初次加载失败移除对应空条目，后续公共请求可以重试。 |
| B36 | 所有页面读取失败都被永久拉黑 | 源读取失败不会永久拉黑页；后续缺页反馈可再次请求。 |
| B37 | 显式 shader 源码与磁盘缓存身份不一致 | 显式 shader 源参与实际身份计算，不写入与磁盘源不相符的缓存。 |
| B38 | 构造失败后已转入字段的 GPU 对象没有清理 | 虚拟阴影已切换字段与 GPU backing 使用同一成功边界；失败保留可重试内容。 |
| B39 | 稀疏映射原生坐标与托管记录不一致 | 稀疏映射的管理记录与原生参数逐项对应，接受后才切换绑定代次。 |
| B40 | 多层附件被固定为单层 rendering | Vulkan rendering 层数来自真实 attachment view 的层范围。 |
| B41 | shading rate image 的设置晚于实际生效时点 | shading rate image 在 BeginRendering 前应用，与声明资源一致。 |
| B42 | 公开允许的空场景和小尺寸不能经过完整流水线 | 空几何跳过无输入的工作链，保留复位、清屏、HiZ 与输出；覆盖 1×1、3×2、非整除容量以及两端空→有内容→空。 |
| S01 | swapchain 初始化失败存在同一 native 引用的双重释放 | swapchain wrapper 接管指针后立即清空原持有位置，失败只释放一次。 |
| S02 | Vulkan 管线构造的清理区间晚于取得 layout | Vulkan 管线创建的清理范围覆盖 shader 归一化与布局后的所有步骤。 |
| S03 | 集合句柄缺少所属集合身份 | 集合句柄同时包含集合身份和条目代次。 |
| S04 | 共享源捕获失败又被不完整回滚覆盖 | 拒绝同一资源重复加入；捕获成功后才推进输出位置。 |
| S05 | 同一代原地改写的取消不恢复已发布字节 | 同代次重写保留已发布字节的备份，取消与刷新失败保留恢复、重试义务。 |
| S06 | metadata-only 编码仍被无条件要求线性属性存储 | metadata-only 功能可不安装实例存储；需要实例的 API 显式检查其依赖。 |
| S07 | 有符号整数先转 uint 再转 float | 有符号整数保持有符号数值直到具体字段类型的编码步骤。 |
| S08 | 范围包含的无符号减法仍可下溢 | 包含关系先限制相对起点，再执行无符号减法。 |
| S09 | 纹理初始完成条件没有覆盖每个子资源的首次使用 | 纹理每个子范围的首个消费者分别继承初始完成条件。 |
| S10 | General 内部区域之间的依赖未进入实际屏障位置 | 边界明确：同一 pass 内不能把同一资源在不兼容布局间当作子 pass 切换；应声明不同 pass。冲突在提交前拒绝。 |
| S11 | rendering region 的位置和数组层范围未被执行消费 | 区域 X/Y/宽高进入执行描述；数组层选择由 attachment view 独占。D3D12 clear/discard/resolve 使用相同矩形。 |
| S12 | 诊断序列化不能表示 query/shader-table 资源 | 诊断导出包含 query 与 shader table 资源、查询范围和计数前缀语义。 |
| S13 | 不同 hit group 复用同一 hit shader 被重复名检查拒绝 | 共享 hit shader 导出复用已有条目；shader 与 hit group 名字分别校验。 |
| S14 | 多个运行选项解析成功却不被 Runtime 消费 | 移除无效启动选项，旧开关不再被静默接受。 |
| S15 | 相机右方向与右手视图的屏幕右方向相反 | 相机右方向使用 forward×up，与屏幕右方向一致。 |
| S16 | 持久参数创建在取得 descriptor 引用后仍有未保护区间 | 持久参数构造的清理边界从 descriptor 捕获后立即开始。 |

## M/G 项判定

| 项目 | 结论 |
| --- | --- |
| M01–M03 | 删除无消费者的 descriptor 退休链、空 scratch 容器及重复辅助代码。 |

| M05 | shader 编译产物为布局依据；移除 Vulkan 活跃资源参数表、按类型重排和 SPIR-V 位置猜测兜底。 |
| M06 | 保留 CPU BVH 是范围读取、重定位及增量补丁的实际需要；CPU 页暂存、GPU 驻留与资产源各有不同生命周期。 |
| M07 | 材质移除同时清除其请求记录。 |
| M08 | 基准调用统一使用 IGraphicsBackend，删除只有一个实现的泛型转发层。 |
| M09 | 剔除复用共享 bounds/HiZ 计算。 |
| M10 | UI、Cluster 回读及上传消费图的实际范围状态；整帧完成集合只保护其实际覆盖的存储代次。 |
| M11 | 分类系统只删除自身实际写入的实体分类。 |
| M12 | 使用 IncrementalHash；删除无法避免原生工作、只重复保存原始 shader 数据的 state-object 缓存。 |
| G01–G02 | 恢复基准结果时逐 workload 比较当前 shader 内容身份；manifest 写入真实编译器 build tag。 |
| G03 | ThreeQueuePresent 仅证明其声明的命令与呈现路径，不作为完整计算→复制→消费数据链证据。本次 GPU 行为测试使用实际数据回读。 |
| G04 | 未把预热平台标记升级为未被要求的通过条件，也不据此宣称普适性能结论。 |
| G05 | 删除只运行启动参数消费者的 RuntimeAllocationTrace，避免继续保留无效工具。 |

## 适用限制

Vulkan Presentation 在现有公共行为中仍明确拒绝，本次未新增该能力；Vulkan 完整几何路径通过无窗口测试验证。当前机器没有 VK_LAYER_KHRONOS_validation，因此没有宣称 Vulkan 原生验证层通过。D3D12 使用现有验证层与 WARP/可用硬件；没有 Intel 适配器的专用用例按原条件跳过。

功能与图之间保持显式借用生命周期：组合宿主先结束图使用再销毁功能。固定渲染尺寸与窗口呈现尺寸独立；没有添加未约定的动态功能卸载、热更 shader 协议或自动全功能 resize。没有把本次正确性测试解释为零分配、全硬件性能或全部失败注入覆盖。
