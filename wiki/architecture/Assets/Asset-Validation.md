# 资产校验与行为验证

> **重构范围说明（2026-09-12）。** [冻结原则](Asset-Rebuild-Principles.md)与[执行任务](Asset-Rebuild-Tasks.md)只替换本次明确讨论的设计。本页中与之冲突的段落待更新，未涉及的架构继续适用；历史验证仅代表当时结果。现有序列化与存储能力的保持依据见[源码审查](Asset-Serialization-Review.md)。

校验先确认值和状态是否已经由内部流程建立不变量。需要检查时，优先使用引擎统一的、可在运行时关闭的 validation 能力；只有真正影响功能的检查才留在必经运行路径。职责边界见 [[Asset-Responsibilities]]。

## 输入边界与内部不变量

| 场景 | 校验依据 |
| --- | --- |
| 存储返回条目与字节 | 请求的身份、所选存储版本、类型与格式是否一致 |
| 外部二进制文件 | 文件结构、编码类型、块位置与长度、完整性和读取限制 |
| 创建具体资源对象 | 对该类型实际运行有意义的条件，如必要 Shader 入口、纹理负载或材质父级关系 |
| 生成字段访问与复制 | 由编译期类型关系保证，不用每次运行的类型 ID 比较补救 |
| 当前依赖描述 | 只枚举实际引用，不附加整套业务验证或脏状态扫描 |
| 工程目录校验 | 离线检查缺失文件、悬空引用与源记录问题 |

存储版本与文档版本不能混同，详见 [[Asset-Identity-and-Dependencies]]。外部文件类型识别允许在输入边界发生，但不授权运行时逐字段操作表，详见 [[Asset-Code-Generation]]。

## 失败与取消是公开行为

保存失败或取消应清理本次临时文件，保留原目标。一个文件等待者取消不影响其他等待者。读取失败后可以修复来源并重新打开；已关闭对象的使用按公共关闭行为失败。

对象更新需要区分提交前失败与提交后通知、清理失败。测试应验证调用方可观察的内容和存活关系，而不是假定所有异常都代表回滚，见 [[Asset-Loading-and-Lifetime]]。

## 测试范围

测试只覆盖行为与公共 API，不断言内部存储布局、生成代码字符串、私有方法清单或具体算法的拼写。等价实现应能保持测试通过。该原则也连接 [[Product-Boundary]]。

| 行为 | 应证明的结果 |
| --- | --- |
| 创建、编辑、保存、重开 | 当前值、身份、名称、来源和输出信息符合各自语义 |
| 共享分支与保留读取 | 已完成的独立写入不改变其他分支或读取者 |
| 显式 I/O 与生命周期 | getter 不隐藏加载；关闭一个持有者不破坏其他保留者 |
| 材质覆盖 | 缺省、零值、空纹理、Reset、父级类型与循环行为明确 |
| World 往返 | 已注册组件、缓冲区、实体身份与引用通过既有 ECS 格式恢复 |
| 运行对象更新 | 身份保持，失败、取消与旧内容保留符合公开边界 |
| 外部声明生成 | 非引擎内部程序集可以声明和使用新资产类型 |

不能用字节或标量分支测试通过，推导任意嵌套元数据已经正确。尚未确认的写入形式见 [[Asset-Open-Questions]]。

## Native AOT 与收尾条件

“没有反射”不是 Native AOT 验证结果。需要实际发布原生产物并运行，覆盖生成入口、具体类型加载和所涉及的资源行为。

本次完整迁移的收尾需要实际完成全量构建、相关行为测试和 Native AOT 发布运行。某个独立子集通过只能证明该子集；被编译错误挡住的导入器、工具或测试必须明确记录。

临时探针、运行脚本与结果完成使用后立即清理。架构说明与验证记录只维护在结构化 wiki；日期结果不会自动升级为永久保证，现有证据见 [[Asset-Verification-2026-09-10]]。
