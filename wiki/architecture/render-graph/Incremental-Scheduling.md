# Incremental Scheduling

## Definition
排序关系变化后只修复受影响的 DAG 区域。

## Invariants
- 自动选择队列的复制 pass 先减少前驱交接，再减少直接消费者显式队列的交接；消费者队列或依赖编辑沿现有增量调度更新。
- 从 predecessor/successor 发生变化的 pass 开始。
- 沿真正受影响的相邻节点传播。
- 已缓存结果与新结果一致时停止传播。
- 不因为一个局部 edge 变化重新排序整个 graph。

## Current design
具体动态拓扑算法可替换；本页只固定局部更新语义。

资源的版本顺序分析共用当前显式依赖的祖先搜索结果。每轮依赖分析按实际查询的
pass 计算祖先位集，资源通过与自身使用者相交获得排序约束，随后按声明顺序处理
同时就绪的使用者。搜索工作区随下一轮分析刷新，显式依赖仍由原图数据持有。
包含循环的关系沿原资源投影处理，资源版本及有效 pass 的循环检验保持原行为。

命令记录单元按显式参数、资源绑定和 barrier 数据的变化维护。一个可回放单元同时包含变化段与
保持原数据的段时，记录器在这些段之间保存边界；后续帧沿这些边界回放原命令并记录变化段。
边界随 pass 的显式移除清理，参数在帧间交替变化沿已有单元执行。图的 command context pool
继续持有命令存储，已提交命令及其资源由原 GPU completion 生命周期回收。
