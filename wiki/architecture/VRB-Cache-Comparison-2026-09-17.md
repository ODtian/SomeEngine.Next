# 2026-09-17 软件光栅顶点缓存对照

> 历史测量说明：本报告比较的是当天较早的 range + 64-entry rolling cache 实现。工作树随后改为 VRB wave + lane-local opaque user vertex / user-defined visibility varying；因此下面的寄存器/LDS A/B 数据不代表当前正式 SW 架构，只保留为实验记录。

## 结论

在本机 RTX 3080 上，保持几何、VRB、binning、材质和顶点求值数量相同，干净的 1 KiB LDS 版在软件光栅 GPU 区间上小幅优于当前寄存器版。静态约节省 2.75 μs，动态连同阴影 SW 约节省 37.82 μs，WPO/透明裁剪约节省 0.74 μs。不能据此宣称完整帧会大幅加速。

关闭 GPU 时间戳测量后，默认动态完整帧均值为 5.698 → 5.596 ms，约下降 1.8%；默认静态为 2.223 → 2.236 ms，没有改善。WPO 完整帧两轮对照的幅度差异很大，不能把首轮约 20.5% 当作可复现收益。位移场景不执行本次替换的普通 SW 顶点缓存，可作为噪声对照。

完整单帧 1 ms 目标没有达到。本轮没有修改正式光栅实现，没有恢复旧 VRB 截断或残余三角形转 HW 的做法，也没有留下 A/B 双路径。原工作树仍保留寄存器版。

## 对照定义

A 是开始实验时工作树的代码：wave32，每 lane 两个 float4，跨 lane 读取，沿局部顶点编号每次推进 32 个，缓存跨同一光栅范围内的三角形块复用。包括当前已有的全 wave 参与顶点读取修正，不能与当天更早构建的帧时间直接比较。

B 只改变缓存存储和读取：64 个 float4 放在组共享内存；新顶点求值完成后做一次一致的组同步；三个角直接按局部顶点编号读取。两版的顶点求值循环、range、顶点解释、材质、裁剪和像素工作分发相同。B 不恢复旧 dedup 或逐 VRB 光栅提交，因此本实验隔离的是缓存存储方式，而不是旧算法整体与新算法整体。

开始时将当前工作树复制到隔离目录。默认几何只生成一次，WPO 和位移各生成一次；之后同一场景目录只交换三个包含 SW 入口的着色器资源。C# 程序、几何、binning、光照、TAA、阴影、HW、细分和表面着色入口不变。每次交换核对资源 SHA256。

## 字节码核验

用相同的 d3d12-sm6.6-bindless 配置分别编译 DXIL 和 SPIR-V，并从最终资源提取每个入口的实际代码比较。

| 场景 | 非 SW 入口逐字节相同 | 发生变化的 SW 入口 |
|---|---:|---:|
| 默认 | 36 | 12 |
| WPO/透明裁剪 | 36 | 12 |
| 位移 | 52 | 12 |

变化的入口仅为三个资源各自的两种 SW 原子输出入口、两个后端；HW、着色及细分入口字节码相同。DXIL 反汇编中，A 没有组共享顶点数组；B 有 `[256 x float]` 的共享数组与组同步，容量 1,024 字节。两版都请求 wave32。像素工作分发的 wave 指令保留，不属于本次缓存替换。

A 的核心源码 SHA256：8711F7BA441AADA6F8658648294CD57D869EB519D844FE148DABB236B60B912F。

B 的核心源码 SHA256：077E7AE26B989C944D380D508E1CDD30113218BED8FA594803CC37DCE972619E。

没有测量驱动生成的机器码寄存器数量、溢出或占用率。源码与 DXIL 不能替代这些指标。

## 测量口径

设备为 Xeon E5-2698B v3、RTX 3080，驱动 610.74；Release，D3D12，1280×720。固定动画步长 0.016666667 秒，关闭垂直同步和调试界面，保留正常 VSM 和 TAA，不降低细分预算。没有锁定频率，没有排除所有桌面活动。

四个场景分别按 A→B→B→A 执行。每次 2,000 帧，剔除最初 500 帧，只按预先确定的预热规则剔除；其余长尾全部保留。每个场景每版合计 3,000 个有效帧。WPO 完整帧另按 B→A→A→B 复测，同样每版增加 3,000 帧，单独报告，不替换第一轮。

GPU 区间和完整帧来自不同运行。GPU 运行在 SW 回调的 ExecuteIndirect 前后写时间戳，结束点之后解析结果；呈现帧等待 GPU 完成后再读取。测得 graphics queue 时钟为 1,000,000,000 ticks/s。每帧测得主视图两阶段和阴影两阶段共四对时间戳，每轮有效区间 6,000 对，完整 GPU 对照共 96,000 对。

GPU 表是每帧四个 SW 区间的合计，含间接调度及 GPU 调度影响，不是纯顶点 ALU 时间。没有将并行 CPU 耗时与它相加。

完整帧运行关闭时间戳、解析和 CPU 读回，也关闭 GPU 校验与像素导出；保留当帧 GPU 完成等待和呈现调用。它不是多帧流水提交间隔，也不是显示器扫描延迟。带时间戳运行的完整帧数值不混入正式完整帧表。

测量代码只存在于隔离构建，在现有录制回调外加时间戳，不增加渲染图节点、资源访问或依赖，不改变场景输入。两版使用同一测量程序。隔离构建有两条缺少 Git 远端所致的 SourceLink 警告，没有构建错误；未更换依赖版本。

## GPU 区间结果

单位 μs；分位数由两次运行的所有有效帧合并后重新计算。

| 场景 | A 均值 | B 均值 | B 减少 | A P50 | B P50 | A P95 | B P95 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 默认静态 | 61.346 | 58.591 | 2.755 / 4.49% | 60.416 | 57.344 | 67.584 | 64.512 |
| 默认动态，含相机和灯光运动 | 441.033 | 403.216 | 37.817 / 8.57% | 422.912 | 392.192 | 663.552 | 434.176 |
| WPO 与透明裁剪，运动 | 51.695 | 50.953 | 0.742 / 1.44% | 51.200 | 50.176 | 56.320 | 57.344 |

静态四次 SW 区间均值依次为 61.368 / 58.177 / 59.006 / 61.324 μs；动态为 438.655 / 403.395 / 403.038 / 443.411 μs；WPO 为 51.634 / 51.310 / 50.595 / 51.756 μs。静态和动态的方向在前后顺序中一致，但 WPO 的差异很小，P95 也没有改善。

动态主视图两阶段合计 58.599 → 55.597 μs；阴影两阶段合计 382.434 → 347.619 μs。主要差异来自阴影 SW。阴影页分配在重复运行之间会变化，因此不能把总计 37.817 μs 全部归结为同一批几何上纯缓存指令的差值。

位移场景的普通 SW 工作计数为零。四个空调度区间均值 A/B 为 9.392 / 11.027 μs，中位数均为 8.192 μs。这些不是执行顶点缓存得到的性能，不能用于评价两种缓存。该场景真正工作的细分入口未改变。

## 完整帧结果：时间戳关闭

单位 ms，每行每版 3,000 个有效帧。

| 场景 / 轮次 | A 均值 | B 均值 | A P50 | B P50 | A P95 | B P95 |
|---|---:|---:|---:|---:|---:|---:|
| 默认静态 | 2.223473 | 2.236060 | 2.1788 | 2.1846 | 2.5113 | 2.5370 |
| 默认动态 | 5.697790 | 5.596265 | 5.6544 | 5.5514 | 6.1684 | 6.0548 |
| WPO，第一轮 A→B→B→A | 3.037978 | 2.415689 | 2.8637 | 2.3441 | 4.2213 | 2.8661 |
| WPO，复测 B→A→A→B | 2.455173 | 2.336667 | 2.3170 | 2.2687 | 2.9403 | 2.7791 |
| 位移，未执行被替换的缓存 | 12.926958 | 13.137860 | 12.8859 | 12.9190 | 14.9023 | 15.7461 |

静态 B 反而增加约 12.59 μs，不构成完整帧改善。默认动态 B 减少约 101.52 μs，约 1.78%；这个幅度不能全归因于 GPU SW 区间本身，后者减少约 37.82 μs。

WPO 首轮 A 两次均值 3.1433 / 2.9326 ms，B 为 2.3969 / 2.4345 ms；复测 A 为 2.3441 / 2.5662 ms，B 为 2.3013 / 2.3720 ms。复测中 A 保留了一帧 58.1859 ms 的长尾。首轮约 20.5%、复测约 4.8% 的整帧差值幅度并不一致，原因尚未定位，不能把其中任一百分比当作已证明的通用收益，更不能用约 0.74 μs 的 SW GPU 差值解释全部变化。

位移没有执行被替换的普通 SW 缓存，B 仍有一次均值和长尾升高，说明本机整帧测量存在不可忽略的运行间波动。没有删除这些结果。

36 份正式追踪均完成、无丢事件或作用域错误。常规完整帧加 WPO 复测共 30,000 个有效帧，没有一帧低于 1 ms。GPU 测量的 24,000 个有效帧独立保留，不混算。

## 功能验证与边界

四场景各两版，均使用 GPU 校验、120 帧固定步长和最终像素读回，全部完成并通过可见输出检查。默认静态两版均为主视图 4,148 个 SW cluster 和 4,148 个 SW work；WPO 两版主视图均为 8 SW + 20 HW，包含阴影共 103 个 SW work；位移两版普通 SW 工作均为零，细分 patch 为 16,594，容量丢弃为零，但均报告 205 次触及既有质量限制。

正常阴影开启时，默认静态 A/B 最终像素有 53,116 个字节不同，动态有 94,294 个；WPO 有一个字节差 1，位移逐字节相同。默认静态 A 自身再跑一次也有 60,773 个像素字节不同。不能声称完整 VSM 输出已经逐像素等价。

诊断时只关闭 VSM、保留 TAA，默认静态、默认动态和 WPO 三组 A/B 最终像素全部逐字节相同。这些诊断没有进入性能表。该结果支持普通渲染输出一致，但不是对所有输入的形式化证明。
