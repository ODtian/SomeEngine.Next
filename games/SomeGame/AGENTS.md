# SomeGame 工作范围

本目录是 monorepo 中的游戏工作目录。仓库根目录为 `../..`，通用代码风格和验证规则见 [根级 AGENTS.md](../../AGENTS.md)。

探索前读取 [领域读取规则](../../docs/agents/domain.md)、[术语入口](../../GLOSSARY-MAP.md)、[游戏术语](GLOSSARY.md) 与 [游戏目标](docs/Game-Goals.md)。

玩法、内容、经营数据和游戏文档在本目录维护；通用物理、动画、渲染、UI 与保存能力在引擎目录维护。游戏通过公开引擎能力组织数据和行为。

游戏工程入口为 `Game.slnx`，构建方式见 [README.md](README.md)。需求规格与任务票沿用 [仓库 Issue tracker](../../docs/agents/issue-tracker.md)，公共行为检查沿用 [行为检查规则](../../wiki/harness/Behavior-Checks.md)。
