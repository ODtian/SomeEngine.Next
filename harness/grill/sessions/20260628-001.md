     复杂度 O(N + screen)，与粒子数无关；空气边缘 = depth clear jump 天然 sharp；
     "粒子之间无缝" 由 smooth pass 实现。

## Q14: Akinci smooth pass 用什么算法
A: （用户：你自己调研啊，为什么问我） → agent 决定 = bilateral filter，
   5-tap separable × 2 pass。van der Hoos 2017 edge-preserving 形式：spatial kernel 平滑
   粒子之间的 step seams，range kernel 在大深度跳变处给零权重保护空气边缘 sharp。

## Q15: 能量守恒噪声怎么注入而不让静止帧抖动
A: （agent 决定）= 在 smoothed depth → normal 后的 iso-surface 上做 hash-based 零均值位移扰动。
   哈希输入是 (viewPos, primitiveId) 等空间坐标，不含 time；静止帧 dt=0 时位移=0、无视觉抖动;
   粒子流动时新像素产生位移，能量只在可见 surface 上耗散。这是 nvidia DirectX SDK water demo 的
   standard 做法。noise amplitude 遵守零均值与 L2 norm clamp 做能量守恒。
