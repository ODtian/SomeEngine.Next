# Grill runtime-surface-fluid-demo

## Q1: 你先用普通语言说：这个 demo 打开后，你希望第一眼看到什么画面/感觉？
A: 是一个让粒子能在表面移动的demo，用于模拟体液运动，目前先用精液。分为三部分，第一部分是表面数据结构，把整个mesh变成一个邻接图结构，存在lod，用于快速跨越长距离，lod几月nanite的方法生成而不是普通lod，因为nanite方式生成lod，不同lod的三角之间天然具有局域关系。第二部分是精液模拟，精液是粘液而不是普通液体，有张力，有粘度，和普通水相比更容易形成大的悬挂液滴，不同液滴之间也会更容易黏在一起不易拉断，因此不是只模拟表面一层粒子，而是精液的所有形态都要模拟出来，且行为一致高度拟真。3是精液的渲染，必须要正确模拟精液视觉效果，直接拿真实精液图片对照，有任何不一致都要全部打回，此外空中的精液和表面的接触检测不要使用代理碰撞体，而是基于深度图，还原世界坐标，并查询visibility查询到三角形，再从三角形查询到对应的表面数据结构。作为模特的必须是一个女人的带骨骼体的mesh，且必须有多种动作来查看是否真的能在动态的网格体上运行
